# 🛒 Marketplace API 

---

## 📌 Описание проекта

Проект представляет собой REST API маркетплейса, который позволяет:

- управлять товарами
- создавать и отслеживать заказы
- работать с пользователями

Данные хранятся в **PostgreSQL**, приложение запускается через **Docker Compose**, тестирование автоматизировано через CI.

---

## ⚙️ Базовый функционал

### Управление товарами

- создание, обновление, удаление товаров
- просмотр списка товаров
- фильтрация (по категории, цене)

---

### Заказы

- создание заказа с набором товаров
- отслеживание статуса:
  - NEW
  - PROCESSING
  - COMPLETED

---

### Пользователи

- хранение данных пользователей в PostgreSQL

---

### База данных

```
users
- id
- name
- email

products
- id
- name
- description
- price
- category

orders
- id
- user_id
- order_date
- status

order_items
- id
- order_id
- product_id
- quantity
- price
```

---

### Инфраструктура

- PostgreSQL
- PgAdmin
- Docker Compose
- GitLab CI (автотесты)


### ⭐ Рейтинг товаров

- пользователь может поставить оценку (1–5)
- рейтинг пересчитывается после каждой оценки
- средний рейтинг отображается в товаре

---

### 💬 Отзывы

- пользователь может оставить отзыв
- отзыв содержит:
  - рейтинг
  - текст
  - дату
- отзывы отображаются на странице товара
- поддерживается сортировка:
  - по дате
  - по рейтингу

---

### ❤️ Избранное

- пользователь может:
  - добавить товар в избранное
  - удалить из избранного
  - получить список избранных товаров
- данные сохраняются в профиле пользователя

---

## 🗄 База данных

### Таблица reviews

```
reviews
- id (PK)
- user_id (FK)
- product_id (FK)
- rating (1–5)
- comment
- created_at
```

---

### Таблица favorites

```
favorites
- id (PK)
- user_id (FK)
- product_id (FK)
```


## 🧪 Интеграционные тесты

Используется:

- Testcontainers
- PostgreSQL (в контейнере)

---

### Покрытие тестами

#### CRUD

- создание
- чтение
- обновление
- удаление


#### Интеграция функционала

- взаимодействие:
  - товары + отзывы
  - товары + рейтинг
  - пользователи + избранное
  - заказы + товары

---

### Требования к тестам

- изолированная среда
- независимость тестов
- корректная очистка данных
